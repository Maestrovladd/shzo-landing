Инструкция: залить продающую страницу в GetCourse

Дата пакета: 26 сентября 2026. Версия 2026-09-26-r70.

Что отдаём

  • prodazha.html — готовый фрагмент. Его и вставляете.
  • Этот файл с шагами.
  • README_ДЛЯ_ТЕХСПЕЦА.txt — короткая шпаргалка.

Эталон вида:
maestrovladd.github.io/shzo-landing/prodazha.html?r=70

Критично для iPhone. Вставляйте файл как есть: это уже фрагмент без <html> и <body>. Полный документ внутрь блока GetCourse = белый экран через секунду.

После заливки в коде должен быть маркер: fragment-no-html-body и shzo-build: 2026-09-26-r70.

1. Вставить HTML

  1. Выключите шапку сайта, меню курса, чат поддержки и «powered by GetCourse».
  2. Поле «CSS страницы» очистите полностью.
  3. Сотрите старый HTML целиком.
  4. Вставьте prodazha.html от первой строки до последней. Не вырезайте скрипт is-phone и Figtree.
  5. Сохраните. Правки «одной строкой» в редакторе не делать.

2. Картинки

Сейчас все картинки открываются с GitHub Pages (maestrovladd.github.io/shzo-landing/assets/…). Если после заливки какая-то пустая — загрузите файл в GetCourse и замените адрес в HTML.

3. Как смотреть

Только живая ссылка в инкогнито. Не редактор. Сверьте с эталоном на GitHub.

4. Прогон

  • Компьютер ≥1100: герой текст слева / фото справа, не столбик.
  • MacBook 1440×900 в широком окне — это десктоп, не телефон.
  • Телефон 375/390: столбик, кнопки на ширину, тарифы столбиком.
  • «Занять место» скроллит к тарифам.
  • Android Chrome: светлая страница, Figtree, не Open Sans.
  • iPhone Safari: 2 минуты без белого экрана.

Не повторять старые ошибки

  • Не определять телефон по screen.height ≤ 900.
  • Не вставлять полный HTML с doctype в блок GetCourse.
  • Не класть второй CSS в поле страницы.
  • Не ставить fetch + document.write автообновление.
  • Не селектор вида .page.is-phone,html.is-phone .foo{display:none} — прячет всю страницу.
